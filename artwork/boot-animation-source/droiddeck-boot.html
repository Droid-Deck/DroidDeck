Use it as the Steam startup movie

  1. Put the .webm file in ~/.steam/root/config/uioverrides/movies/. Create the folders if they don’t exist.
  2. In Steam, open Settings > Customization > Startup Movie and pick it.

Which file to ship

Ship the dark version if your Steam UI is dark: it hands off to the library without a bright flash. The 1280×800 cut matches Steam Deck and is the safe default. The 1920×1080 cut is sharper on phones and TVs. Steam needs the .webm; the .mp4 files are for sharing. Everything is drawn and synthesized in code, so the included scripts can output any other size.
