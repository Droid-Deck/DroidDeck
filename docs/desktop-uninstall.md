# Uninstall desktop mode

Choose **Uninstall** beside **Open desktop**, then confirm. The same action is available under
**Desktop → Files**. Stop any running session and let other installs finish first.

Removal keeps Steam, games, added apps, settings, modified files and shared dependencies. It uses
the pinned desktop file inventory and only removes matching files. Unknown desktop versions and
missing runtime package ownership cause removal to fail before deleting files.

An interrupted desktop install also offers Uninstall. Successful removal clears that desktop
installation's recovery record and cached download so the next guest launch cannot reinstall it
through package recovery. If removal is interrupted, choose Uninstall again to retry. Open desktop
installs the desktop again when needed.
