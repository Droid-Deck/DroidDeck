# DroidDeck 0.5.0

### Features

- Added **SteamVR support on Android**, using Valve's ARM64 SteamVR runtime to run PC VR games through Proton. Includes experimental Cardboard VR with stereoscopic rendering, lens correction and head tracking, plus immersive SteamVR on Meta Quest with native OpenXR tracking and Touch controller support. Quest 2, 3 and 3S work through the standard APK, with VR game compatibility still experimental. (@xXJSONDeruloXx, @Jagger15, [#642](https://github.com/Droid-Deck/DroidDeck/pull/642), [#676](https://github.com/Droid-Deck/DroidDeck/pull/676), [#704](https://github.com/Droid-Deck/DroidDeck/pull/704), [#910](https://github.com/Droid-Deck/DroidDeck/pull/910))
- Added **XR glasses support** for VITURE, RayNeo and experimental XREAL models, with external display output, refresh-rate and brightness controls, head tracking, virtual-screen viewing and SteamVR. Also supports Joy-Cons as tracked VR controllers and experimental camera-based hand tracking. Available features vary by model. (@maxjivi05, @informalTechCode, [#732](https://github.com/Droid-Deck/DroidDeck/pull/732), [#907](https://github.com/Droid-Deck/DroidDeck/pull/907))
- Added **Epic's native Linux Games Launcher**, running under FEX with automatic sign-in using your linked Epic account. Browse, install and launch games directly, with touchscreen and controller navigation. Epic games launch through Steam for Steam Input and the performance overlay, with fallback to the existing launch method where needed. (@maxjivi05, [#928](https://github.com/Droid-Deck/DroidDeck/pull/928))
- Added a **Storage page** under Setup, showing space used by games, Proton versions, shader caches, prefixes, desktop apps and system files. Includes cleanup for unused runtimes, leftover game data, cached components and old logs, with safeguards for installed games and saves. (@xXJSONDeruloXx, [#913](https://github.com/Droid-Deck/DroidDeck/pull/913))
- Added **custom Steam startup animations**, with a choice of 30 or 60 FPS, a sound toggle and support for importing your own videos. Imported clips are converted to a Steam-compatible format when needed. (@xXJSONDeruloXx, [#969](https://github.com/Droid-Deck/DroidDeck/pull/969))
- Added **automatic GPU driver updates and rollback** in Auto mode, keeping recommended drivers current and restoring the last working driver pair if an update repeatedly fails to start a session. Manual and mixed configurations are left unchanged. (@xXJSONDeruloXx, [#972](https://github.com/Droid-Deck/DroidDeck/pull/972))
- Added **GOG and Epic achievements** to game details and the session drawer, with unlock progress, achievement icons and filters for locked, unlocked and hidden achievements. GOG also supports optional achievement syncing through Comet, including unlock notifications. (@phobos665, @xXJSONDeruloXx, [#641](https://github.com/Droid-Deck/DroidDeck/pull/641), [#651](https://github.com/Droid-Deck/DroidDeck/pull/651), [#775](https://github.com/Droid-Deck/DroidDeck/pull/775))
- Added **Metacritic scores, HowLongToBeat estimates, developer, publisher and release information** to GOG and Epic game details, with a redesigned layout for game information and achievements. (@phobos665, @xXJSONDeruloXx, [#712](https://github.com/Droid-Deck/DroidDeck/pull/712), [#775](https://github.com/Droid-Deck/DroidDeck/pull/775))
- Added **sorting and list views for GOG, Epic and Amazon libraries**, with options for title, size, release date, recently played and recently installed. View and sort preferences persist across sessions. (@kingokksa, [#798](https://github.com/Droid-Deck/DroidDeck/pull/798))
- Added a per-game **Start without Steam** option for games that fail to launch or immediately close when started through Steam. (@The412Banner, [#659](https://github.com/Droid-Deck/DroidDeck/pull/659))
- Added **Reset all settings** under Setup → Diagnostics, restoring defaults while preserving games, accounts and downloads, with an option to reset game profiles. (@0x1Nawaf, [#696](https://github.com/Droid-Deck/DroidDeck/pull/696))
- Added experimental **Android Auto support**, allowing DroidDeck to appear on compatible car displays when enabled through Android Auto developer settings. (@zekena2, [#952](https://github.com/Droid-Deck/DroidDeck/pull/952))

### Improvements

- Redesigned **GPU driver management** with clearer selection modes, live display and runtime driver information, and improved driver switching and restart handling. (@xXJSONDeruloXx, [#858](https://github.com/Droid-Deck/DroidDeck/pull/858))
- **Downloads now resume after interruption** and can automatically switch to alternative sources when a download stalls. Expanded download-source selection across Steam, the Linux runtime, GPU drivers, Flatpak setup and other components. (@kingokksa, @ovurrsl, [#623](https://github.com/Droid-Deck/DroidDeck/pull/623), [#847](https://github.com/Droid-Deck/DroidDeck/pull/847))
- Added optional **low-latency controller and touch settings**, increasing input polling to 1000 Hz and reducing touchscreen buffering. Both settings can be changed during a session. (@xXJSONDeruloXx, [#808](https://github.com/Droid-Deck/DroidDeck/pull/808))
- Added optional **zRAM compression for Steam**, reducing the client's resident memory usage while games are running. Also reduced background CPU and process overhead by consolidating Steam web helpers and session services. (@maxjivi05, @xXJSONDeruloXx, [#442](https://github.com/Droid-Deck/DroidDeck/pull/442), [#566](https://github.com/Droid-Deck/DroidDeck/pull/566), [#575](https://github.com/Droid-Deck/DroidDeck/pull/575))
- Improved **CPU allocation on Snapdragon 8 Gen 2 devices**, defaulting games to performance cores and Steam to the prime core while preserving existing preferences. On Odin 3, Android performance hints now help demanding game threads reach prime cores when needed. (@xXJSONDeruloXx, @kmnkv1, [#654](https://github.com/Droid-Deck/DroidDeck/pull/654), [#682](https://github.com/Droid-Deck/DroidDeck/pull/682))
- Improved **frame pacing and refresh-rate handling**, including more accurate presentation timing, fixed-refresh frame limiting and adaptive frame generation pacing. (@xXJSONDeruloXx, [#715](https://github.com/Droid-Deck/DroidDeck/pull/715), [#717](https://github.com/Droid-Deck/DroidDeck/pull/717), [#753](https://github.com/Droid-Deck/DroidDeck/pull/753), [#927](https://github.com/Droid-Deck/DroidDeck/pull/927))
- Improved **Steam and store artwork**, with editable artwork synchronized between DroidDeck and Steam's grid folder, expanded SteamGridDB searches, sharper home-screen shortcuts and featured artwork that prioritizes your Steam library. (@FX192, @xXJSONDeruloXx, @KirkPatrickJunsay, [#876](https://github.com/Droid-Deck/DroidDeck/pull/876), [#939](https://github.com/Droid-Deck/DroidDeck/pull/939), [#948](https://github.com/Droid-Deck/DroidDeck/pull/948), [#825](https://github.com/Droid-Deck/DroidDeck/pull/825), [#835](https://github.com/Droid-Deck/DroidDeck/pull/835), [#878](https://github.com/Droid-Deck/DroidDeck/pull/878))
- Reworked **Epic and Amazon game downloads and installation**, with improved verification, more efficient temporary storage usage, adaptive parallel downloading and better handling of insufficient storage. (@The412Banner, @jmarti326, [#802](https://github.com/Droid-Deck/DroidDeck/pull/802), [#710](https://github.com/Droid-Deck/DroidDeck/pull/710))
- **DroidDeck-Proton updates now come from the Droid-Deck organization repository**, with existing installations and update detection preserved. (@The412Banner, [#875](https://github.com/Droid-Deck/DroidDeck/pull/875))
- Added **23 more languages**, bringing the app to 32 language options besides English, with expanded translations for newer features and existing languages. (@maxjivi05, @Dantalian-dev, [#669](https://github.com/Droid-Deck/DroidDeck/pull/669), [#539](https://github.com/Droid-Deck/DroidDeck/pull/539))
- Improved **controller support**, including mapping supported controllers' rear paddles to Steam Deck L4/R4, a three-finger gesture for Steam's on-screen keyboard, and a complete gamepad layout for second-screen controls. (@Vynex, @xXJSONDeruloXx, @ovurrsl, [#797](https://github.com/Droid-Deck/DroidDeck/pull/797), [#782](https://github.com/Droid-Deck/DroidDeck/pull/782), [#895](https://github.com/Droid-Deck/DroidDeck/pull/895))
- Improved **foldable display handling**, automatically hiding the unfolded touch gamepad when a controller connects and adding top, bottom and centered picture positions for Steam sessions. (@Gustash, @asdf17128, [#829](https://github.com/Droid-Deck/DroidDeck/pull/829), [#871](https://github.com/Droid-Deck/DroidDeck/pull/871))
- Added **component downloads from the session drawer** and combined SteamVR and Cardboard controls into a single VR tab. (@xXJSONDeruloXx, [#679](https://github.com/Droid-Deck/DroidDeck/pull/679), [#959](https://github.com/Droid-Deck/DroidDeck/pull/959))
- Improved **session diagnostics**, with actual on-screen frame-pacing measurements, additional process-exit information and more reliable log preservation following unexpected shutdowns. (@xXJSONDeruloXx, @ovurrsl, @kmnkv1, [#855](https://github.com/Droid-Deck/DroidDeck/pull/855), [#897](https://github.com/Droid-Deck/DroidDeck/pull/897), [#513](https://github.com/Droid-Deck/DroidDeck/pull/513))

### Fixed

- Fixed **Android UI flickering on affected Adreno 740 devices**, including the AYN Thor, when using certain Turnip driver configurations. (@xXJSONDeruloXx, [#963](https://github.com/Droid-Deck/DroidDeck/pull/963))
- Fixed **controller rumble stopping after one second** when a game requests continuous vibration. (@TideGear, [#938](https://github.com/Droid-Deck/DroidDeck/pull/938))
- Fixed **Batman: Arkham City** crashing on startup under FEX and getting stuck during redistributable installation. (@TjebbeKerstens, [#792](https://github.com/Droid-Deck/DroidDeck/pull/792), [#793](https://github.com/Droid-Deck/DroidDeck/pull/793))
- Fixed **Steam community touch layouts not applying correctly** when a game starts, including layouts downloaded from the Steam Workshop. (@xXJSONDeruloXx, [#840](https://github.com/Droid-Deck/DroidDeck/pull/840))
- Fixed **Steam's Shut Down and Restart options**, and sessions unexpectedly closing after multiple Steam client restarts. (@muazkadan, @KirkPatrickJunsay, [#629](https://github.com/Droid-Deck/DroidDeck/pull/629), [#754](https://github.com/Droid-Deck/DroidDeck/pull/754))
- Fixed the **Quick Access Menu button not responding** with Xbox and PlayStation controller emulation. (@muazkadan, [#631](https://github.com/Droid-Deck/DroidDeck/pull/631))
- Fixed **non-Steam game shortcuts failing to launch** when Steam takes too long to load a large library, with a bounded wait before forwarding the launch to Steam. Also fixed store games incorrectly switching to their Steam installations when owned on both platforms. (@xXJSONDeruloXx, @ovurrsl, [#758](https://github.com/Droid-Deck/DroidDeck/pull/758), [#914](https://github.com/Droid-Deck/DroidDeck/pull/914), [#973](https://github.com/Droid-Deck/DroidDeck/pull/973), [#816](https://github.com/Droid-Deck/DroidDeck/pull/816))
- Fixed **Steam crashes sometimes returning silently to the launcher**, preserving crash status and showing the existing error screen, including when VR runtimes are installed on Quest. (@xXJSONDeruloXx, [#905](https://github.com/Droid-Deck/DroidDeck/pull/905))
- Fixed **Quest display corruption** affecting Steam, Desktop and transitions between sessions. (@Jagger15, [#733](https://github.com/Droid-Deck/DroidDeck/pull/733))
- Fixed **Linux runtime installation failures on 16 KB page-size devices**, Flatpak installation on older Android kernels and PRoot startup problems on devices with unusual kernel behavior. (@ovurrsl, @xXJSONDeruloXx, @xXPOLYGONXx, [#900](https://github.com/Droid-Deck/DroidDeck/pull/900), [#752](https://github.com/Droid-Deck/DroidDeck/pull/752), [#457](https://github.com/Droid-Deck/DroidDeck/pull/457))
- Added the **Android all-files permission needed for raw USB storage volumes**, allowing users to grant access when a drive is exposed outside the usual storage path. Access and game execution still depend on the device. (@Imgau, [#760](https://github.com/Droid-Deck/DroidDeck/pull/760))
- Fixed **battery charging and remaining-time estimates** displaying incorrect values on devices that report battery current in milliamps. (@muazkadan, [#820](https://github.com/Droid-Deck/DroidDeck/pull/820))
- Fixed **wired PowerA and PDP controller mapping**, along with touchpad clicks, cursor movement, physical keyboard input and several foldable layout issues. (@Raidennrl, @KirkPatrickJunsay, @Gustash, @ovurrsl, [#692](https://github.com/Droid-Deck/DroidDeck/pull/692), [#644](https://github.com/Droid-Deck/DroidDeck/pull/644), [#772](https://github.com/Droid-Deck/DroidDeck/pull/772), [#832](https://github.com/Droid-Deck/DroidDeck/pull/832))
- Fixed **microphone capture in DirectAudio games** and installation of .NET Core and Desktop runtime components. (@xXJSONDeruloXx, @The412Banner, [#747](https://github.com/Droid-Deck/DroidDeck/pull/747), [#740](https://github.com/Droid-Deck/DroidDeck/pull/740))
- Fixed **GOG and Epic achievements remaining stuck on Reading**, store background tasks unexpectedly closing the app and failures during cloud-save recovery. (@xXJSONDeruloXx, @KirkPatrickJunsay, @ovurrsl, [#961](https://github.com/Droid-Deck/DroidDeck/pull/961), [#846](https://github.com/Droid-Deck/DroidDeck/pull/846), [#898](https://github.com/Droid-Deck/DroidDeck/pull/898))
