# DroidDeck 0.2.0 (beta)

First public beta. DroidDeck runs Valve's native ARM64 Steam client on Adreno Android devices, with Windows games through Valve's ARM64 Proton and FEX, plus an optional Linux desktop with emulators.

**Needs:** Android 9+, Adreno 730 or newer (or 8xx), ~3 GB free for the runtime (+1.1 GB for Desktop & apps). No root.

## New

- Launcher redesign: side rail, Games tab with list and detail pages, Steam capsule wall with hero art and last played, graphite theme, controller hints, phone-width layouts by @xXJSONDeruloXx in #35, #41
- Components manager: pick FEX, DXVK and VKD3D-Proton per Proton build, download or import `.wcp`, swap mid-session; applied on every launch including non-Steam shortcuts by @The412Banner in #29
- Decky Loader support, with plugins loading in Big Picture by @xXJSONDeruloXx in #16
- Paged session drawer with Display, Controls and Settings tabs on LB/RB by @xXJSONDeruloXx and @The412Banner in #6, #24
- Change the suspend policy mid-session by @xXJSONDeruloXx in #14
- On-screen controller editor in Setup, with adaptive sticks and phone-sized layouts by @maxjivi05 in #9
- Big Picture's Switch to Desktop works and opens the desktop with Steam running by @The412Banner in #18
- Dolphin, melonDS and Cemu launch full screen from the front end with working defaults by @The412Banner in #10, #18, #42
- Steam won't start while Android's child-process limit is on; Setup can lift it over wireless ADB and remembers the pairing by @xXJSONDeruloXx in #21
- Share session logs from the app or the ended-session screen, which now has Retry by @xXJSONDeruloXx in #17, #41
- DroidDeck startup movie by default, and optional Steam startup by @xXJSONDeruloXx in #25, #36, #38

## Security

- SHA-256 required for every catalog, release and Proton download by @xXJSONDeruloXx in #40
- Runtime archives can't hard-link outside the rootfs by @xXJSONDeruloXx in #40
- Logs scrub Steam account and persona names, public IPs and device IDs by @The412Banner in #19

## Known issues

- Emulator coverage is uneven; most have only been tested on one or two devices.
- Desktop compositing is software-rendered.
- Firefox runs with a reduced sandbox under proot.
- Adreno 710/720/722 need imported drivers and are unverified.

Report problems with the log folder from `Download/DroidDeck/` attached.
