# DroidDeck 0.2.0 (beta)

First public beta. DroidDeck runs Valve's native ARM64 Steam client on Adreno Android devices, with Windows games through Valve's ARM64 Proton and FEX, plus an optional Linux desktop with emulators.

**Needs:** Android 9+, Adreno 730 or newer (or 8xx), ~3 GB free for the runtime (+1.1 GB for Desktop & apps).

This is the first release from the [Droid-Deck](https://github.com/Droid-Deck) org, so the list below covers everything DroidDeck does, not only what changed since 0.1.7. Links to `The412Banner/DroidDeck` are pull requests from before the move; entries without a link were built before the project took pull requests.

## Steam

- Valve's native ARM64 Steam client under gamescope, drawn by DroidDeck's own Vulkan Wayland compositor; the client is fetched from Valve on your device and never redistributed by @The412Banner
- Windows games through Valve's ARM64 Proton and FEX, with the ARM64 Proton ready before the client first needs it by @The412Banner in The412Banner/DroidDeck#22, #33
- Start offline, once you have signed in at least once by @The412Banner
- Steam Deck mode: SteamOS helper stubs, battery and NIS in the Quick Access Menu, and a MangoHud performance overlay by @The412Banner in The412Banner/DroidDeck#9, The412Banner/DroidDeck#16
- Your own games from any folder show up in Steam as non-Steam games under ARM64 Proton, with store art by @The412Banner in The412Banner/DroidDeck#9
- Components manager: pick FEX, DXVK and VKD3D-Proton per Proton build, download or import `.wcp`, swap mid-session; applied on every launch including non-Steam shortcuts by @The412Banner in #29
- GE-Proton and proton-cachyos as extra compatibility tools, managed in place by @The412Banner and @xXJSONDeruloXx in The412Banner/DroidDeck#18
- FEX presets per session, from Stability to Extreme + TSO by @The412Banner
- Decky Loader support, with plugins loading in Big Picture by @xXJSONDeruloXx in #16
- Steam's Settings → Internet page and connection indicator work, through a NetworkManager stand-in by @maxjivi05
- Steam sees the device as "DroidDeck" by @xXJSONDeruloXx in #15
- Steam launchers on the Linux desktop run the client there, with the same sign-in and settings by @The412Banner in #10
- DroidDeck startup movie by default, and an option to launch straight into Steam when the app opens by @xXJSONDeruloXx in #25, #27, #36, #38

## Display and performance

- Frame generation in the compositor: built-in Win-FG, or LSFG from your own copy of Lossless Scaling, 2×–4×, changeable mid-game by @The412Banner
- Import or download Turnip drivers for the runtime and the display, per mode, from Banners-Turnip and WinNative releases by @The412Banner
- Resolution and display shape per mode, including "Exactly this panel" for 4:3 and 3:2 handhelds, and 16:9 on foldables by @The412Banner in The412Banner/DroidDeck#14
- Stretch games to fill the screen, and Quake-engine games windowed at the session's size by @The412Banner in The412Banner/DroidDeck#32
- HDR10 output on panels that support it (experimental) by @The412Banner
- Runs as a game on Android: sustained performance, the panel's fastest mode and ADPF hints by @The412Banner
- Steam's interface stays on the GPU, where it used to fall back to CPU drawing by @maxjivi05
- Pin the Steam client and games to chosen CPU cores, plus fallbacks for devices where sessions won't stay up by @The412Banner
- Faster proot, built from source with WinNative's seccomp and tracing fixes by @maxjivi05 in #4, #37
