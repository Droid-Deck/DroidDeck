# DroidDeck 0.2.0 (beta)

First public beta. DroidDeck runs Valve's native ARM64 Steam client on Adreno Android devices, with Windows games through Valve's ARM64 Proton and FEX, plus an optional Linux desktop with emulators.

**Needs:** Android 9+, Adreno 730 or newer (or 8xx), ~3 GB free for the runtime (+1.1 GB for Desktop & apps). No root.

## New

- **Launcher redesign.** Side rail, Games tab with list and detail pages, Steam capsule wall with hero art and last played, graphite theme, controller hints throughout. Scales down to phone-width screens.
- **Components.** Pick FEX, DXVK and VKD3D-Proton per Proton build. Download from the catalog, import `.wcp`, or swap from the in-session drawer. Choices apply on every game launch, including non-Steam shortcuts.
- **Decky Loader.** Install and manage Decky from the app; plugins load in Big Picture.
- **Session drawer.** Tabs for Display, Controls, Settings and Components, switchable with LB/RB. Change the suspend policy mid-session.
- **On-screen controller editor** in Setup, with adaptive sticks and phone-sized layouts.
- **Switch to Desktop works.** Big Picture's power menu and the drawer's Desktop button open the desktop with Steam's desktop client running.
- **Emulators from the front end.** Dolphin, melonDS and Cemu launch full screen with working defaults (game folders, Vulkan, audio, guide button toggles full screen).
- **Process limit check.** Steam won't start while Android's child-process limit is active; Setup can lift it over wireless ADB, and remembers the pairing.
- **Share session logs** from the app, or from the ended-session screen along with Retry.
- **Optional Steam startup movie**, DroidDeck's by default.

## Improved

- First sign-in installs Valve's ARM64 Proton before the client needs it, instead of after a restart.
- Faster proot, from WinNative's seccomp and tracing fixes.
- Runtime installs in a foreground service, so leaving the app no longer interrupts it.
- Touch passes through gamescope directly; the pointer follows it in Passthrough mode.
- Buttons, text and tabs sized for handhelds; honors the system animation scale.

## Fixed

- Steam updates failing on read-only content files.
- A dropped finger-up blocking all later touches.
- Stopping a session leaving orphaned processes that could fill storage with log output.
- Launcher restarting when a controller connects.
- Concurrent runtime installs racing each other.

## Security

- Every catalog, release and Proton download is checked against a SHA-256 before use.
- Runtime archives can't write hard links outside the rootfs.
- Logs strip Steam account and persona names, public IPs and device IDs.

## Known issues

- Emulator coverage is uneven; most have only been tested on one or two devices.
- Desktop compositing is software-rendered.
- Firefox runs with a reduced sandbox under proot.
- Adreno 710/720/722 need imported drivers and are unverified.

Report problems with the log folder from `Download/DroidDeck/` attached.
