# DroidDeck 0.5.0-wallentx.4

Experimental PowerVR, Mali, and Xclipse fork preview. Install the same package variant as your existing wallentx build to update in place and retain app data.

## Get the matching GPU components

1. Install the APK below; the file without a package suffix is the standard app.
2. Open **Components > GPU drivers > Sources**. The **Runtime driver** page also has a **Sources** button.
3. Choose **Add repository**, enter `wallentx/DroidDeck` in **GitHub owner/repository**, and press **Save**. If the fork is already listed, make sure it is visible instead of adding it twice.
4. Refresh the component list. Download the new **System Vulkan** build from `wallentx/DroidDeck` for your GPU (PowerVR, Mali, or Xclipse), and select it as the runtime driver. Auto can install the recommended build when no component is installed; existing installations should select the new build explicitly.
5. Stop the current session and start Steam again so the APK helpers and selected runtime are both active.

GPU component sources are separate from **Update Sources**. Adding the fork only on the Updates page does not configure GPU downloads. Keep Android's system driver selected for display; the downloadable bundle supplies the guest runtime.

## Changes

- PowerVR: remove SPIR-V debug names before shader creation to avoid the driver's input/output name collision that produced flat-color frames in Megabonk (#8).
- PowerVR: preserve dynamic vertex input for Zink, fixing missing Balatro/LÖVE text on the contributor's tested device (#9).
- MangoApp: handle unreadable Android sysfs directories and use the PowerVR presentation path so the performance overlay can stay running (#10).
- Include the launcher startup fix, the System Vulkan static TLS reservation for Steam, and automatic placed-memory handling for managed experimental Mali 32-bit games. These no longer require local environment overrides.
- Integrate current main while preserving the fork's GPU routing, component management, and session staging.

Thanks to @coffeemeist3r for the three PowerVR fixes, focused tests, and detailed device reproductions.

## Validation and limits

PowerVR device results above were reported by the contributor on a Pixel 10 Pro Fold. The earlier TLS and Mali defaults were verified with Portal reaching its rendered menu on a Pixel 8 Pro (Mali-G715, driver 54.3.0). Those results do not establish compatibility with every game or GPU; the combined release still needs broader device testing.

Build, signing, component provenance, and checksum details are attached to this release.
