# What droiddeck-msi-install runs: msitools' msiinfo reads a Windows Installer package's tables
# and streams, cabextract unpacks its cabinets (every compression a cabinet can use, which gcab
# alone cannot), 7-Zip (7z + its 7z.so format plugin) opens the installer .exe wrappers around
# packages (self-extracting 7-Zip and cabinet files, WiX bundles). Arch Linux ARM's aarch64 packages, hosted unchanged on this repo's
# msitools-0.106-r1 release because the mirror keeps only the newest of each. CI fetches each,
# checks the sha256 and stages the files below into the apk under usr/local/lib/droiddeck-msitools;
# SessionFiles copies them into the runtime at every launch. Everything else they need (glib, gio,
# libxml2.so.16, zlib, bzip2, libgcc_s) is in the runtime already.
